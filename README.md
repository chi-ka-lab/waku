# 枠 WAKU — 稼働メーター

タスクを絶対に忘れないことと、稼働時間を確保することだけに最適化した、1人用の
タスク＋稼働時間管理アプリ。

- **単一ファイル**（`index.html`）。ビルド不要・サーバー不要・オフライン動作
- **データは端末の中だけ**（localStorage）。請求データが外部に出ません
- **スマホ対応**（ボトムナビ＋FAB、ホーム画面に追加可）

## 公開URL

**https://chi-ka-lab.github.io/waku/**

- スマホでもこのURLを開けば **Google連携が使えます**（HTTPSのため）
- 共有メニュー →「**ホーム画面に追加**」でアプリとして起動できます（オフライン動作）
- 更新は `./deploy.sh` を実行するだけ（1分ほどで反映）

> リポジトリは public ですが、**あなたのデータは1件も入っていません**。
> 入っているのはアプリのコードと匿名のサンプル枠（クライアントA/B/C）だけです。
> 実データはブラウザの localStorage と、あなたの Google ドライブにあります。

## 端末間の同期（Google ドライブ）

**データはブラウザごとに別です。**PCで入れた実績はスマホには出てきません。
これを揃えるのが Google ドライブ同期です。

- 保存先は **あなたの Google ドライブの appDataFolder**（アプリ専用の隠し領域）
  他のアプリからは見えず、ドライブ画面にも出ません。**サーバーは介在しません**
- 設定 →「端末間の同期」→「**いま同期する**」
- **自動で同期**をONにすると、変更の20秒後とタブを閉じるときに自動送信
- 別の端末で更新されていたら**選択ダイアログ**が出ます

| 選択肢 | 動き |
|---|---|
| この端末を送る | ローカルでクラウドを上書き |
| クラウドを取り込む | クラウドでローカルを上書き |
| **統合する（推奨）** | タスク・実績・確定・学習内容を **id で足し合わせ**、枠や設定は新しい方を採用 |

**適用の直前に必ず自動バックアップを取ります。**「直前の状態に戻す」でいつでも戻せます。

## ローカルで起動（開発用）

```bash
./serve.sh          # → http://localhost:8765
./serve.sh 9000     # ポート指定
```

`index.html` をダブルクリックでも開けますが、Safari など一部ブラウザは
`file://` で保存が効きません。**必ず `./serve.sh` で開いてください。**

### スマホで使う

1. Mac で `./serve.sh` を起動（表示される `http://192.168.x.x:8765` を控える）
2. スマホを同じ Wi-Fi に繋ぎ、そのURLを Safari / Chrome で開く
3. 共有メニュー →「ホーム画面に追加」でアプリのように使えます

> PC とスマホでデータは共有されません（それぞれの端末に保存）。
> 移す場合は 設定 →「書き出す（JSON）」→ もう一方で「読み込む」。

## 2つの不変条件

| | 守るもの | 仕組み |
|---|---|---|
| 🔒 | **絶対に忘れない** | 入口は受信箱ひとつ（枠も見積も聞かない）／持ち越しは消えず最上段に固定／夜のゲートで受信箱0・未割当0にしないと閉じられない |
| ⏱ | **稼働時間を確保する** | 週初に「時間を先に取る」でカレンダーへ先に置く／未確保時間を常時表示／予備ブロックを毎日確保 |

ヘッダーの **受信箱** と **未確保** が両方 緑なら、システムは動いています。

## 使い方（1日3分 + 週10分 + 月6分）

| いつ | 画面 | やること |
|---|---|---|
| 月初 3分 | 今月 | `先月の枠をコピー` → 予算hをタップして直す → `定型を生成` |
| 週初 5分 | 週 | `時間を先に取る` を押す。未確保が 0 になる |
| 毎朝 2分 | 今日 | 持ち越しを処理／2〜3件足す／バーが赤なら1件落とす |
| 日中 3秒 | どこでも | `⌘K` / 右下の ＋ で受信箱に投げる。✓ で完了 |
| 毎夜 1分 | 今日 | `今日を閉じる` → 残りと受信箱を処理して閉じる |
| 週末 5分 | 今月 | ▲▼ の枠を1つだけ手当て（枠を移す／削る／追加請求） |
| 月末 3分 | 請求 | `月を確定する` → CSV書き出し |

## 時刻でカウントする枠（何時〜何時）

クライアントによっては「3.5h」ではなく「9:00〜12:30」で報告・請求する必要があります。

1. **設定 → 枠の「時刻」にチェック**を入れる
2. その枠のタスクは、実測欄が **時間数ではなく時刻レンジ**（`9:00–12:30`）になります
3. 入力方法は3つ
   - **▶ タイマー**：押した時刻と止めた時刻がそのまま記録される
   - **✓ 完了**：カレンダーに確保した時刻から自動で `開始–終了` が入る
   - **時刻欄をタップ**して `9:00-12:30` と直接入力（`22:00-1:00` の日跨ぎも可）
4. **請求画面に「時刻明細（勤務記録）」**が自動で出ます（日付／枠／作業／開始／終了／時間）
5. **実績CSV** に `記録方式 / 開始 / 終了` の列が入るので、そのまま提出できます

時間数でよい枠は今までどおり。**枠ごとに混在できます。**

## Google カレンダー連携

**確保した時間をカレンダーに送る**のが主目的です（予定が入っていれば守れる）。
逆方向（Googleの予定 → WAKUの実績）はレビューを挟んで取り込みます。

### A. .ics で書き出す（設定不要・全端末で使える）

週の画面の **「カレンダーへ送る」**、または 設定 → **「.ics で書き出す」**。
Google カレンダー → 設定 → **インポート** で読み込みます。
`UID` を付けているので、同じ週を再インポートしても**重複しません**。

### B. API で直接つなぐ（取り込みができる／PCのみ・初回5分）

アプリの **設定 → Google カレンダー連携 →「セットアップ手順」** を開くと、
リンク付きのウィザードが出ます。**このURLの生成元は自動表示＋コピーボタン付き**なので、
貼り間違いが起きません。

1. [プロジェクトを作成](https://console.cloud.google.com/projectcreate)（名前は何でも可）
2. [Google Calendar API を有効化](https://console.cloud.google.com/apis/library/calendar-json.googleapis.com)
3. [OAuth 同意画面](https://console.cloud.google.com/auth/overview) → 外部 → アプリ名・メールを入力
   → [対象ユーザー](https://console.cloud.google.com/auth/audience) で **テストユーザーに自分の Gmail を追加**
4. [クライアント作成](https://console.cloud.google.com/auth/clients) → **ウェブ アプリケーション**
   → **承認済みの JavaScript 生成元**に `http://localhost:8765`（リダイレクトURIは空でOK）
5. 発行されたIDをウィザードに貼り付け →「保存して接続する」

### つまずいたとき

失敗すると **原因ごとの対処モーダルが自動で開きます**（リンク付き手順＋「直したのでもう一度つなぐ」）。
手動で開くには 設定 →「**うまくいかない時は**」。

| Googleに出るメッセージ | 原因 | 直し方 |
|---|---|---|
| アクセスをブロック：…審査プロセスを完了していません<br>`403: access_denied` | テストユーザー未追加 | [対象ユーザー](https://console.cloud.google.com/auth/audience) → テストユーザー → **＋ Add users** にログイン用の Gmail を追加 → 1〜2分待って再接続 |
| `400: origin_mismatch` / `invalid_client` | JavaScript生成元の不一致 | [クライアント設定](https://console.cloud.google.com/auth/clients) の「承認済みのJavaScript生成元」に `https://chi-ka-lab.github.io` と `http://localhost:8765` を追加（末尾スラッシュなし） |
| `Calendar API has not been used…` | API未有効 | [Calendar API](https://console.cloud.google.com/apis/library/calendar-json.googleapis.com) を有効にする |
| 認証ウィンドウが開かない | ポップアップブロック | ブラウザでこのサイトのポップアップを許可 |

> **テスト状態だとトークンが7日で切れます。**毎回の再認証が面倒なら、
> [対象ユーザー](https://console.cloud.google.com/auth/audience) で「**アプリを公開**」→ 本番環境 に切り替えると
> テストユーザー管理が不要になります（「確認されていないアプリ」の警告が出ますが、**詳細 → 安全でないページに移動** で進めます）。

**「接続テスト」**ボタンで、認証とカレンダー読み取りまで一気に確認できます。
設定欄の下に **診断パネル**（接続元 / クライアントID / 認証）が常時出ます。
失敗したときは、原因の見当（生成元ミス／API未有効／テストユーザー未追加）がトーストで出ます。

### 週・今日に Google の予定が重なって表示されます

接続すると、**週グリッドと今日のタイムライン**に Google の予定が
**破線の薄いブロック（読み取り専用）**として重なります。左レーンが Google、右レーンが WAKU の確保です。

- **「時間を先に取る」は Google の予定を避けて配置します**（会議の上に確保を置きません）
- ゴーストを**クリックすると1操作で実績に取り込め**ます
- 画面を開くと自動で同期（2分キャッシュ）。設定のチェックで表示ON/OFF

### 予定の取り込み（まとめて）

設定 →「**予定を取り込む**」（青いボタン）。

| 機能 | 動き |
|---|---|
| 期間切替 | 今週 / 今月 / 先月 をその場で切り替え |
| **自動判定** | タイトルに枠名・クライアント名が入っていれば**枠が自動で選ばれる** |
| **学習** | 一度取り込んだタイトルは記憶され、次回から自動で同じ枠になる |
| 一括 | 「全部この枠に」→ 適用 →「枠が決まった行をすべて取り込む」 |
| 個別 | 行ごとに枠を選んで「取り込む」／「×」で今後非表示 |

取り込むと **完了済みの実績**として登録され、**開始〜終了時刻もそのまま入ります**
（時刻枠ならそのまま提出用CSVに載ります）。

**二重計上の防止**

- WAKUが作った予定には印が付き、候補から自動除外
- 一度「取り込む」か「×」した予定は次から出てこない
- 辞退した予定・終日予定・キャンセル済みは最初から対象外
- 確保ブロックの再送は**更新**なので、Google側に重複が作られない

> **HTTPSなら制約はありません。**公開URL（https://chi-ka-lab.github.io/waku/）なら
> スマホでもAPI連携が使えます。制約が出るのは `http://` のLAN IPで開いたときだけです。
> アクセストークンは**保存していません**（タブを閉じると切断）。端末に残るのはクライアントIDのみです。

## 提出用CSV（クライアントごと）

請求画面の **「提出用CSV」** に、その月に実績のあるクライアントが並びます。
**プレビュー**で中身を確認 → **CSV** で書き出し。**全クライアントぶんを書き出す**で一括も可能。

**時刻で記録する枠**は、これだけで提出できる書式で出ます。

```
稼働報告書
クライアント,クライアントB
対象期間,2026-09-01 〜 2026-09-30
提出者,○○デザイン / 山田 太郎
作成日,2026-09-16
契約時間,20.0 h

日付,曜日,開始,終了,休憩,実働(h),実働(時:分),作業内容
2026-09-01,火,9:00,12:30,0:00,3.50,3:30,定例打ち合わせ
2026-09-02,水,13:00,17:30,0:45,3.75,3:45,LINE構築 実装
2026-09-03,木,9:00,12:00,0:00,3.00,3:00,架電レポート作成
,,,,合計,10.25,10:15,

契約時間,20.0
消化時間,10.25
残時間,9.75
単価,12000
金額,123000
```

**時間数の枠**は `日付 / 曜日 / 作業内容 / 時間(h)` のシンプルな書式になります。

- 提出者名・屋号は 設定 →「提出情報」で登録（ヘッダーに入ります）
- **休憩**は請求画面の「時刻明細」で分単位で入力。実働時間が自動で引かれます
- ファイル名は `2026-09_クライアントB_稼働報告.csv`

## 見た目

- 既定は**明るいテーマ**。ヘッダー右の `☾` / `☀` でダークに切り替えられます（設定は保存されます）
- 「今日を閉じる」と「今週ぶんの確保が完了」したときに紙吹雪が出ます

## 設定画面の開き方

**ヘッダー右の ⚙（歯車）** から開きます。PCでは上部タブの「設定」からも入れます。
スマホのボトムナビは 今日／受信箱／週／今月／請求 の5つで、**設定は歯車から**です。

## 接続の保持

Google の接続（アクセストークン）は **この端末に約1時間ぶん保存**され、
**リロードしても接続が切れません**。期限が切れたら設定で「接続する」を押し直してください。

- 現在の状態は 設定 → Google カレンダー連携 の **診断パネル**（接続元／クライアントID／認証）で確認できます
- 「接続中 ── 15:40 まで有効」のように期限も表示されます
- 端末から消したいときは「**切断**」。「全部消す」でも一緒に削除されます

## 操作

| 操作 | 効果 |
|---|---|
| `⌘K` / `Ctrl+K` | どこからでも受信箱に追加 |
| `Esc` | 閉じる |
| ✓ | 完了。実測が無ければ**見積が実績になる**（空欄を作らない） |
| ▶ | タイマー開始／停止。止めた時間が実績に入る |
| 見積・実測の数字をタップ | その場で編集 |
| ⋯ | 明日へ／今週へ／日付指定／枠変更／開始時刻／捨てる |
| 時刻欄をタップ | `9:00-12:30` の形で稼働時刻を直接入力（時刻枠のみ） |
| `☾` / `☀` | 明るい／暗いテーマの切替 |
| タイトルをタップ | 名前を編集 |

## データ

- 保存先：ブラウザの localStorage（キー `waku.v1`）
- **バックアップ**：設定 →「書き出す（JSON）」を定期的に。ブラウザのデータを消すと失われます
- CSV：請求画面から「実績CSV」「請求CSV」（Excel で開ける BOM 付き UTF-8）
